Create or reuse a recurring heartbeat in the current chat using the available runtime scheduling tool when the completed kickoff is submitted. Interval: five minutes. Do not create shell cron jobs as a substitute for a thread heartbeat. Record the actual automation ID, active/paused status and scheduler-reported next run in workflow-state.json. Never claim the timer runs because this file exists.

Pause this watchdog only at that full delivery scope or explicit user pause. If scheduling/publication is blocked, expose the exact blocker and recommended remediation; never silently omit it.
